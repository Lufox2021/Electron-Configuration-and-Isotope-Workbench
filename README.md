# Electron Configuration & Isotope Workbench

A practice tool for general chemistry students. Given a specific isotope of an atom or ion (H–Xe, main-group ions, and transition-metal cations), students:

1. Work out the nucleus: given two of protons (Z), neutrons (N) and mass number (A), find the third. When only A and N are given, the element symbol is hidden until Z is found.
2. Count the electrons.
3. Write the electron configuration (full or noble-gas core notation).
4. Choose the needed sublevels and fill in an orbital box diagram using the Aufbau principle, Hund's rule and the Pauli principle.
5. Decide whether the species is diamagnetic or paramagnetic, and count unpaired electrons.

**Coaching** mode checks each step and explains which rule was broken. **Testing** mode gives no feedback until the end, then shows a score and a summary that can be printed or saved as a PDF for Blackboard.

Everything is in one self-contained page, `index.html`. No install is needed; open the GitHub Pages link.

Notes on the answer keys:
- Only naturally occurring isotopes are used.
- Elements with irregular configurations are left out (Cr, Cu, Nb, Mo, Ru, Rh, Pd, Ag, and Cu⁺), as is Tc, which has no natural isotopes. No f orbitals are used.
- Students choose the levels and sublevels they need before filling in the orbital diagram. Unpaired electrons may be drawn all spin-up or all spin-down.
- Transition-metal cations lose 4s electrons before 3d (Fe²⁺ = [Ar]3d⁶).
